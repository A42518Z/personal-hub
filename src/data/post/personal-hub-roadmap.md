这个站点不是一个普通博客，而是一个个人集网站。

第一阶段的目标是先把核心骨架搭稳：

- 首页：展示个人介绍、快速入口、项目和状态。
- 博客：记录成长、技术复盘和生活随笔。
- 导航：整理常用网站、AI 工具、前端文档和学习平台。
- 项目：沉淀项目入口、截图、亮点和复盘。
- 工具箱：逐步加入 JSON、时间戳、Base64、正则等小工具。
- 实验室：存放动效、Canvas、WebGL 和 3D 实验。
- 状态页：展示本地服务、Docker 和 API 健康检查。

后续每个页面都会保持一个原则：页面只做编排，组件负责展示，数据单独维护。

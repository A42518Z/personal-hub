# 为什么SQL语句不要使用过多的join

> [!summary] 速记
> 每个join操作都需要对两个或多个表进行连接操作，需要消耗大量的计算资源和时间，join过多，会导致SQL的执行效率降低 join操作会使得SQL语句变得复杂，难以理解和维护

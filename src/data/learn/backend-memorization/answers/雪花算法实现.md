# 雪花算法实现

> [!summary] 速记
> 雪花算法是一个生成分布式全局唯一id的算法，得到一个长度为64的long类型数据，由四个部分组成。

## 面试回答

雪花算法是一个生成分布式全局唯一id的算法，得到一个长度为64的long类型数据，由四个部分组成。

第一个bit位是一个符号位，因为id不能为负数，所以一般是0

第二部分是由41位的时间戳组成

第三部分是由10个bit位表示工作机器的id

最后用12个bit位表示工作的序列号

# B树和B+树的区别

> [!summary] 速记
> 在B树中，每个节点都包含索引及数据，所以树的层高相对来说会高一些。

## 面试回答

在B树中，每个节点都包含索引及数据，所以树的层高相对来说会高一些。

同时在进行数据查找的时候，由于数据是存储在每个节点的，所以极端情况下要遍历整个树才能找到数据，所以查询时间的稳定性较差

B树的所有叶子节点都在同一层，意味着从根节点到每个叶子节点的距离相等，这样可以保证无论访问哪个叶子节点，时间复杂度都是O(logn)



B+树的非叶子节点只存储索引，所有数据记录保存到叶子节点中，这样可以更好的缩小树的层高，提高查找效率

B+树所有叶子节点通过一个双向指针连接，使得范围查找的效率更高

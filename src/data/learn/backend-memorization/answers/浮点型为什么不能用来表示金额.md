# 浮点型为什么不能用来表示金额

> [!summary] 速记
> 要表示货币的精度，至少要精确的表示0.1或者0.01等货币的数值。

## 面试回答

要表示货币的精度，至少要精确的表示0.1或者0.01等货币的数值。而浮点数是用二进制科学及算法来表示的，它不能精确地表示所有的十进制小数，在进行加减乘除的时候，可能会产生舍入的问题。为了避免这类问题，用专门的货币类型，比如BigDecimal

# 同步和异步有什么区别

> [!summary] 速记
> 同步交互：指发送一个请求，需要等待返回，然后才能发送下一个请求，有个等待过程； 异步交互：指发送一个请求，不需要等待返回，随时可以再发送下一个请求，即不需要等待。

## 面试回答

同步交互：指发送一个请求，需要等待返回，然后才能发送下一个请求，有个等待过程；

异步交互：指发送一个请求，不需要等待返回，随时可以再发送下一个请求，即不需要等待。

区别：一个需要等待，一个不需要等待。

建议使用同步交互的操作，比如银行的转账系统，数据库的保存操作。

其余情况就使用异步交互

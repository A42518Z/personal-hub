# final关键字的作用

> [!summary] 速记
> final修饰变量，表示常量，是不能修改的。

## 面试回答

final修饰变量，表示常量，是不能修改的。

final修饰类：不能被继承

final修饰方法：不能被覆盖，父类的a方法，子类不能覆盖（不能写a方法）

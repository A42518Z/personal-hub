# 介绍类加载过程，什么是双亲委派

> [!summary] 速记
> 我们写的java文件到最终运行，必须要经过编译和类加载这两个阶段。

## 面试回答

我们写的java文件到最终运行，必须要经过编译和类加载这两个阶段。而编译的过程是把.java文件编译为.class文件，而类的加载过程就是把.class文件加载到JVM内存里面，装载完成后会得到一个class对象，我们就可以使用new关键字来实例化这个对象。类的加载过程涉及到类加载器，JVM在运行的时候会产生三个类加载器：启动类加载器（核心类库的加载,rt.jar），扩展类加载器，应用类加载器；三个加载器组成了一个层级关系，每一个类加载器分别去加载不同作用范围的jar包.



双亲委派机制，就是按照类加载器的关系，逐层进行委派，类加载器在加载类时，会先将请求委派给父类加载器处理，只有当父类加载器无法完成类加载时，子类加载器才会尝试加载该类。



优点：

安全性：双亲委派机制确保了核心类库不会被重复加载和篡改。只有启动类加载器才能加载这些核心类库，避免了安全风险

避免类重复加载：通过委派机制，保证了类只会被加载一次，从而节省内存，提高性能

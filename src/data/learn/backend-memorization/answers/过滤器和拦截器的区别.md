# 过滤器和拦截器的区别

> [!summary] 速记
> 运行顺序不同，过滤器是在servlet收到请求之后，被调用之前运行，拦截器是在servlet被调用之后运行 配置方式不同，过滤器是在web.xml中配置，拦截器是通过注解配置的 过

## 面试回答

运行顺序不同，过滤器是在servlet收到请求之后，被调用之前运行，拦截器是在servlet被调用之后运行

配置方式不同，过滤器是在web.xml中配置，拦截器是通过注解配置的

过滤器依赖servlet容器，拦截器不依赖servlet容器

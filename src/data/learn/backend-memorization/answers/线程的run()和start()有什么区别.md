# 线程的run()和start()有什么区别

> [!summary] 速记
> start()方法用于启动线程，run()方法用于执行线程的运行时代码 run()可以重复调用，而start（）只能调用一次

## 面试回答

start()方法用于启动线程，run()方法用于执行线程的运行时代码

run()可以重复调用，而start（）只能调用一次

# 快速排序

> [!summary] 速记
> 核心思路：先找基准，然后右边找出比基准小的，左边找出比基准大的，交换位置，最后两点重合时，与基准交换位置，保证基准左边的数都比基准小，基准右边的数都比基准大。

## 面试回答

核心思路：先找基准，然后右边找出比基准小的，左边找出比基准大的，交换位置，最后两点重合时，与基准交换位置，保证基准左边的数都比基准小，基准右边的数都比基准大。然后采用递归思想，继续左边的排序，右边的排序



源码：

```java
public class QuickStart {
    public static void main(String[] args) {
        int[] a={10,7,2,4,7,62,3,4,2,1,8,9,19};
        quickSort(a,0,a.length-1);
//        for (int i = 0; i < a.length; i++) {
//            System.out.println(a[i]);
//        }
        Arrays.stream(a).forEach(System.out::println);
    }

    public static void quickSort(int[] arr,int low,int height){

        if(low>height){
            return;
        }
        int i=low;
        int j = height;
        int temp,t;

        temp=arr[low]; //temp是基准
        while (i<j){
            //先看右边，依次往左递减
            while (temp<=arr[j]&&i<j){
                j--;
            }

            //再看右边，依次往右递增
            while (temp>=arr[i]&&i<j){
                i++;
            }
            //如果满足条件则交换
            if(i<j){
                t=arr[j];
                arr[j]=arr[i];
                arr[i]=t;
            }


        }
        //此时i和j相遇了，交换基准
        arr[low]=arr[i];
        arr[i]=temp;

        //递归调用左半数组
        quickSort(arr, low, i-1);
        //递归调用右半数组
        quickSort(arr,i+1,height);

    }
}
```

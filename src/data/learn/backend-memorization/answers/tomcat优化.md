# tomcat优化

> [!summary] 速记
> 利用缓存和压缩 对于静态页面最好是能缓存起来，采用Nginx作为静态资源服务器，将图片、css、js文件都进行了缓存，有效的减少了后端tomcat的访问 开启压缩是一种优化网络传输

## 面试回答

利用缓存和压缩

对于静态页面最好是能缓存起来，采用Nginx作为静态资源服务器，将图片、css、js文件都进行了缓存，有效的减少了后端tomcat的访问

开启压缩是一种优化网络传输性能的常见方法，可以减少数据传输量，加快页面加载速度，提高用户体验



调整JVM参数

通过-Xms和-Xmx参数设置初始堆大小和最大堆大小。初始堆大小应根据应用程序的内存需求来设置，而最大堆大小应根据系统的物理内存和应用程序的性能需求来设置



通过-XXParallelGCThreads参数设置并行GC线程数，以提高垃圾回收的效率



调整线程池配置

调整tomcat的线程池配置是优化性能和提高服务器吞吐量的重要步骤。Tomcat使用线程池来处理客户端，合理配置线程池参数可以更好地利用服务器资源，避免线程过多或过少导致性能问题

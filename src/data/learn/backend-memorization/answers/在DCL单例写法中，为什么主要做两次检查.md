# 在DCL单例写法中，为什么主要做两次检查

> [!summary] 速记
> 第一次检查是为了保证只有首次并发的情况下才阻塞，提高性能 第二次检查是为了避免重复创建对象 加锁是为了保证线程安全

## 面试回答

第一次检查是为了保证只有首次并发的情况下才阻塞，提高性能

第二次检查是为了避免重复创建对象

加锁是为了保证线程安全

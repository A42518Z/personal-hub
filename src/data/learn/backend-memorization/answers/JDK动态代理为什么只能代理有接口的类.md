# JDK动态代理为什么只能代理有接口的类

> [!summary] 速记
> 这是JDK动态代理本身的机制来决定的，在java里面，动态代理是通过Proxy.newProxyInstance()这个方法来实现的，它需要传入被动态代理的一个接口类，这是由JDK

## 面试回答

这是JDK动态代理本身的机制来决定的，在java里面，动态代理是通过Proxy.newProxyInstance()这个方法来实现的，它需要传入被动态代理的一个接口类，这是由JDK底层原理决定的。JDK动态代理会在程序运行期间去动态生成一个代理类$Proxy0,这个类会继承Proxy同时还会去实现被代理类的接口。在java中是不支持多种继承的，而每个动态代理类都继承了一个Proxy，所以就导致JDK里面的动态代理只能代理接口，不能代理实现类

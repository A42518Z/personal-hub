# 三次握手的流程

> [!summary] 速记
> 第一次握手，客户端向服务器端发送连接请求报文（SYN报文）。

## 面试回答

第一次握手，客户端向服务器端发送连接请求报文（SYN报文）。连接请求报文中同步位SYN=1，初始序号seq=x。发送SYN报文后，客户端进入SYN SENT（同步已发送）状态，等待服务器应答；

第二次握手，服务器收到连接请求报文后，如果同意建立连接，则向客户端发送确认报文（SYN+ACK报文），然后服务器进入SYN RCVD(同步收到)状态。在确认报文中，SYN位和ACK位都为1，确认序号为ack=x+1，同时为自己设置一个初始序号seq=y；

第三次握手：客户端收到服务器的确认报文后，向服务器发送确认报文（ACK报文）。确认报文中，ACK=1，seq=x+1，ack=y+1。客户端发送此报文后，进入ESTABLISHED状态。服务器端收到此报文后，进入ESTABLISHED(连接建立)状态。此时，双方连接建立，完成三次握手

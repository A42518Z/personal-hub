# 普通类和抽象类的区别

> [!summary] 速记
> 1.实例化：普通类可以直接实例化，抽象类不能直接实例化 2.方法：抽象类中既包含抽象方法，有可以包含普通方法，而普通类只能包含普通方法 3.实现：普通类实现接口需要重写接口中的方法

## 面试回答

1.实例化：普通类可以直接实例化，抽象类不能直接实例化

2.方法：抽象类中既包含抽象方法，有可以包含普通方法，而普通类只能包含普通方法

3.实现：普通类实现接口需要重写接口中的方法，而抽象类可以实现接口方法也可以不实现

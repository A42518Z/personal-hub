# 一个线程调用两次start方法会有问题吗

> [!summary] 速记
> 在java里面，一个线程只能调用一次start()方法，第二次调用会抛出一个IllegalThreadStateException异常 我们第一次调用start方法的时候，线程的状

## 面试回答

在java里面，一个线程只能调用一次start()方法，第二次调用会抛出一个IllegalThreadStateException异常

我们第一次调用start方法的时候，线程的状态可能会处于非NEW状态下的一个其他状态，再调用start方法之后，相当于让这个线程重新执行一遍，不管是从线程安全性角度来看，还是说从线程本身的逻辑来看，都是不合理的（因此在线程运行时，会先去判断线程的运行状态）

## 面试回答

1.中间件通知

MQ中间件：数据更新后，就通知缓存删除

2.延迟双删

先删除缓存 

再写数据库

休眠xxx毫秒

再次删除缓存

说明：第一次删除是为了避免在延时期间有新的请求使用到旧的缓存数据，第二次删除则是在数据库更新完成后彻底移除旧数据，以保持数据一致性

延时的目的是为了确保数据库的更新操作能够完成

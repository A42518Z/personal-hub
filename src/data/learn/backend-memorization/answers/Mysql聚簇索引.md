# Mysql聚簇索引

> [!summary] 速记
> 聚集索引就是基于主键创建的索引，除了主键以外的其他索引，被称为非聚集索引，也叫二级索引。

## 面试回答

聚集索引就是基于主键创建的索引，除了主键以外的其他索引，被称为非聚集索引，也叫二级索引。由于在InnoDB引擎里面，一张表的数据对应的物理文件，本身就是按照B+树来组织的一种索引结构，而聚集索引就是按照每张表的主键来构建一颗B+树，然后叶子节点存储了这个表的每一行数据记录，所以聚集索引并不只是一种索引类型，还代表着一种数据的存储方式。一般情况下建议自增id作为主键，这样的id本身就具有连续性，使得对应的数据也会按照顺序存储在磁盘上，写入性能和搜索性能都很高。InnoDB里面只能存在一个聚集索引,如果存在多个聚集索引，这个表里面会存在多个副本，造成磁盘空间浪费，以及数据维护困难的问题

# 数据量多大的时候要开始分表分库

> [!summary] 速记
> 1.如果单个表的数据量非常大，例如超过了百万级别，就需要开始考虑分表 2.当单个数据库的性能无法满足业务需求时，就需要考虑分库 3.当系统的业务逻辑越来越复杂，不同的业务之间的数据

## 面试回答

1.如果单个表的数据量非常大，例如超过了百万级别，就需要开始考虑分表

2.当单个数据库的性能无法满足业务需求时，就需要考虑分库

3.当系统的业务逻辑越来越复杂，不同的业务之间的数据耦合度越来越低，就需要考虑对系统进行拆分，以方便管理和扩展

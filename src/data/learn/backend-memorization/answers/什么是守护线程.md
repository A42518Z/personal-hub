# 什么是守护线程

> [!summary] 速记
> 守护线程是在程序运行过程中在后台进行的线程，它的任务是为其他线程提供服务和支持。

## 面试回答

守护线程是在程序运行过程中在后台进行的线程，它的任务是为其他线程提供服务和支持。当所有的非守护线程结束运行时，虚拟机会自动退出，不管守护线程的状态如何。java中，通过设置线程的setDaemon方法设置为true，就能将线程设置为守护线程。

守护线程通常用来执行一些辅助性的任务，比如垃圾回收、内存管理等

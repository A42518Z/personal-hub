# 线程池底层的工作原理

> [!summary] 速记
> 1.线程池刚创建的时候，里面没有任何线程，等到有任务过来的时候才会创建线程。

## 面试回答

1.线程池刚创建的时候，里面没有任何线程，等到有任务过来的时候才会创建线程。

2.调用execute()提交一个任务时，如果当前的工作线程数<corePoolSize,直接创建新的线程执行这个任务

3.如果当前工作线程数>=corePoolSize，会将任务放入任务队列中缓存

4.如果队列已满，且线程池中工作线程的数量<maximumPoolSize，还是会创建线程执行这个任务

5.如果队列已满，并且线程池中工作线程已达到maximumPoolSize，这个时候会执行拒绝策略，Java线程池默认的策略是AbortPolicy，即抛出RejectExecutionException异常

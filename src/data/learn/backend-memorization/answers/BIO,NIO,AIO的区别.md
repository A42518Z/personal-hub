# BIO,NIO,AIO的区别

> [!summary] 速记
> BIO是同步阻塞式IO,就是我们平常使用的传统IO，它的特点是模式简单使用方便，并发处理能力低 NIO同步非阻塞IO，是传统IO的升级，客户端和服务器端通过通道通讯，实现了多路复用。

## 面试回答

BIO是同步阻塞式IO,就是我们平常使用的传统IO，它的特点是模式简单使用方便，并发处理能力低

NIO同步非阻塞IO，是传统IO的升级，客户端和服务器端通过通道通讯，实现了多路复用。

AIO是NIO的升级，实现了异步非阻塞IO，异步IO的操作基于事件和回调机制

应用场景：

BIO适用于连接数比较小且固定的架构

NIO适用于连接数比较多且连接比较短的架构，比如聊天服务器

AIO适用于连接数比较多且连接比较长的架构，比如相册服务器

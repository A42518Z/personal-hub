# 为什么数据库字段建议设置位not null

> [!summary] 速记
> 数据的完整性 某个字段允许为空，会导致数据中出现不完整或不一致的情况 查询性能 数据库执行查询的时候，不需要额外处理空值情况，提高查询效率 数据一致性 设置为not null 可以

## 面试回答

数据的完整性

某个字段允许为空，会导致数据中出现不完整或不一致的情况



查询性能

数据库执行查询的时候，不需要额外处理空值情况，提高查询效率



数据一致性

设置为not null 可以在数据库层面强制实施数据一致性约束

# 为什么有些公司禁止使用@Transactional声明式事务

> [!summary] 速记
> 方法上面增加@Transactional声明式事务，如果一个方法中存在较多耗时的操作，很容易引发长事务的问题，而长事务会带来锁的竞争，影响性能 如果方法存在嵌套调用，而被嵌套调用的

## 面试回答

方法上面增加@Transactional声明式事务，如果一个方法中存在较多耗时的操作，很容易引发长事务的问题，而长事务会带来锁的竞争，影响性能

如果方法存在嵌套调用，而被嵌套调用的方法，也声明了@Transactiona事务，那么这个时候会出现事务嵌套的调用行为，容易引起事务混乱，造成程序运行结果出现异常的问题

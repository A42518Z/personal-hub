# 深拷贝和浅拷贝

> [!summary] 速记
> 深拷贝和浅拷贝是用来描述对象或者对象数组引用数据类型的一个复制场景； 浅拷贝就是只复制某一个对象的指针，而不复制这个对象本身，这意味着，这两个指针指向被复制对象的同一块内存地址。

## 面试回答

深拷贝和浅拷贝是用来描述对象或者对象数组引用数据类型的一个复制场景；

浅拷贝就是只复制某一个对象的指针，而不复制这个对象本身，这意味着，这两个指针指向被复制对象的同一块内存地址。

深拷贝就是完全创建一个一摸一样的新的对象，新对象和老对象之间不共享任何内存，也就意味着对新对象的修改不会影响老对象。

实现浅拷贝或者深拷贝，都需要实现Cloneable接口，并且实现clone()方法，然后我们可以在clone()方法里实现浅拷贝或者深拷贝的一个实现逻辑

# Base理论

> [!summary] 速记
> Base理论是对CAP中一致性和可用性权衡的结果，是基于CAP演化而来的。

## 面试回答

Base理论是对CAP中一致性和可用性权衡的结果，是基于CAP演化而来的。

Base理论的核心思想：即使无法做到强一致性，每个应用都可以根据自身业务特点，采用适当的方式达到最终一致性。

BA 基本可用 （Basically Avaliability）

是指在分布式系统钟出现不可知故障的时候，允许损失部分可用性。



S 软状态（S Soft state）

是指系统中数据允许存在中间状态（软状态），并认为这个状态是不影响系统的可用性的。



E 最终一致性 （Eventually consistent）

允许整个系统中数据在经过一定时间后，最终能达到整个系统的一致性。但是这个时间绝对不可以过长。

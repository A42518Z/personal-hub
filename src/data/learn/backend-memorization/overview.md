# 七天背诵总计划

> 目标：7 天完成首轮背诵，形成“能口述、能追问、能关联”的面试题知识网。

## 背诵规则

- 每题按“三段式”：一句话定义 -> 底层原理 -> 场景和坑。
- 当天新题先看速记，再遮住答案口述。
- 每天最后 20 分钟只复盘错题和薄弱题。
- 第 3 天复盘第 1 天，第 5 天复盘第 2-3 天，第 7 天总复盘。

## 自测打分

- 3 分：能完整解释并回答追问。
- 2 分：能说主干，但原理或场景不稳。
- 1 分：只记得关键词。
- 0 分：完全不会。

# 手机批量图片上传页面

## 页面入口

- 路由：`/tools/photo-upload`
- 文件：`src/pages/tools/photo-upload.astro`
- 工具箱入口：`src/data/hub.ts` 中 `tools` 的“图片处理”分组

## 页面能力

该页面面向手机端批量上传图片场景，提供以下能力：

- 一次选择多张相册图片
- 支持通过摄像头拍照上传入口选择图片
- 本地生成图片预览缩略图
- 使用浏览器 `canvas` 将图片压缩为 JPEG
- 默认将最长边限制为 1600px
- 默认压缩质量为 0.82
- 使用队列上传模型，默认最多 3 张并发
- 显示总数、完成数、失败数和整体进度
- 每张图片展示状态、原图大小、压缩后大小和单张进度
- 上传失败后支持单张重试
- 支持清空当前队列

## 当前接口状态

当前页面中的 `uploadImage(item)` 为模拟上传方法，用于验证手机端交互体验。

后续接入真实上传时，只需要替换 `uploadImage(item)` 内部逻辑，例如：

- 上传到本地 API：`/api/photos/upload`
- 上传到 Cloudflare R2 预签名 URL
- 上传到 S3 / OSS / COS
- 上传完成后写入图片元数据 JSON 或数据库

## 推荐后续扩展

- 后端生成预签名上传 URL
- 上传成功后返回 CDN 图片地址
- 记录图片宽高、压缩大小、上传时间和标签
- 增加暂停/继续上传
- 增加按月份或相册分组
- 增加 HEIC 兼容提示或转码流程
